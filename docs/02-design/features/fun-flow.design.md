## 0. Context Anchor

| Key | Value |
|---|---|
| **WHY** | 사용자 결정(2026-09-01): "질문에 답하면서 재미를 얻도록, 흐름을 빠르게." 학술 근거(E): 질문 자체는 재미를 보장하지 않고 **진행감·즉시 피드백·자기표현·완료 신호**와 결합해야 참여가 강해진다 |
| **WHO** | 신인 창작자. 빈 페이지 공포(페인포인트 ①)와 구조 부재(②)를 가진 사람 |
| **RISK** | 게이미피케이션 장식(뱃지·점수)만 붙이면 효과가 없다(E: Mazarakis 2023 — 요소 조합이 자동으로 더해지지 않음). 사적 고백을 강요하는 질문은 역효과(E: 자기개방 연구) |
| **SUCCESS** | 답변 1개마다 화면의 작품 상태가 눈에 보이게 변한다. 2단계 완료율·단계 소요시간이 측정 가능해진다 |
| **SCOPE** | `/create` 5단계 위저드의 표현 계층. 추출·질문 생성 로직(G7·G14로 완료)은 건드리지 않는다 |

## 1. 기능 요구사항

| ID | 요구사항 | 근거 | 우선순위 |
|---|---|---|---|
| R1 | 2단계에서 답변을 제출하면 **즉시** "창작 프로필 카드"(장르·톤·인물 성향·확정 요소)가 갱신되어 보인다 | D패턴1 (Storyweave+16P) | P0 |
| R2 | 각 질문 화면에 **"이 답으로 만들어지는 것"** 한 줄이 표시된다 (예: "주인공의 겉욕망이 정해져요") | D패턴2, E원칙 "다음 질문의 이유" | P0 |
| R3 | 답변 직후 "반영된 것 / 아직 빈 것" 상태가 갱신된다. 진행률은 **질문 개수가 아니라 작품 단위**로 표시한다 (예: "핵심 갈등 확정 · 결말 미정") | E원칙3, E: Jeong 2025(진행 피드백→자기효능감) | P0 |
| R4 | 단계 확정(2→3, 3→4 등) 시 **짧은 전환 연출**(300ms 이내, reduce-motion 존중)이 있다 | D패턴2 (Duolingo 마일스톤) | P1 |
| R5 | 5단계 이야기 지도 완성 시 **명시적 "완료" 화면**(작품 카드 + 다음 행동 2개: 작업실 가기·내보내기)이 있다 | E원칙5 (완료 신호 없으면 자기효능감 손해) | P0 |
| R6 | 모든 질문에 "건너뛰기"가 유지되고, 건너뛴 질문은 다시 나타나지 않는다 (기존 G14 계약 유지) | E원칙4 (자기개방 강요 금지) | P0 |
| R7 | 3단계 로그라인 카드에 **사용자의 답이 어디에 반영됐는지** 표시된다 (예: 답한 문구를 하이라이트) | E: 반영형 피드백(Tsay-Vogel, 추정 표기) | P1 |
| R8 | 장면 입력 후 "확정 사실 / 빈칸 / 다음 후보" **3분할 카드**로 보여준다 (기존 ScenePlacement 확장) | D패턴4 (PlotMachines) | P1 |
| R9 | 위 연출·카드가 추가되어도 **키보드 진행(Enter로 다음)과 단계 이동 속도는 느려지지 않는다** — 애니메이션은 진행을 막지 않는다(non-blocking) | 사용자 결정 "흐름을 빠르게" | P0 |
| R10 | R1~R8의 상태 변화는 **기존 세션 구조(`CreationSession`)에서 파생**해 계산한다. 새 저장 키를 만들지 않는다 | 저장 계층 단순성 유지 | P0 |

## 2. 비목표 (Non-goals)

- 뱃지·점수·스트릭 등 **외적 보상 게이미피케이션** — 근거(E): 요소를 조합해도 효과가 자동으로 더해지지 않으며, 작품 상태 표시가 더 적합
- 질문 생성·추출 로직 변경 — G7·G14에서 완료된 계약을 건드리지 않는다
- 소리·햅틱 — P2 이후
- `/write` 화면 — H1 실험 대조군이므로 그대로 둔다
- 공유 카드(D패턴5의 공유 부분) — 내보내기(G10)와 겹치므로 P2에서 통합 검토

## 5. 데이터 모델

새 저장 키 없음(R10). `CreationSession`에서 파생 계산:
- 확정 요소 = `elements` 중 `value`가 있는 것 (source 무관)
- 명시적 "없음" = `unknown: true` — "빈칸"이 아니라 "묻지 않기로 한 것"으로 표시
- 작품 단위 진행 = 매핑 테이블(요소 키 → "핵심 갈등"·"결말" 등 사용자 언어)로 계산. 질문별 "만들어지는 것" 문구는 `QUESTION_POOL`에 정적 필드로 추가(코드 상수, 방법론 데이터 아님)
