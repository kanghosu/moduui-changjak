## 1. 지금 단계 — 고객 만족 우선 (2026-08-26 ~)

데모(9/5)·심사·초기 사용자 검증 구간에서는 **품질이 비용에 우선한다.**
추출 품질은 제품의 생명선(PRD v2 §4 — "이미 말한 것을 다시 물으면 제품 존재 이유가 사라진다")이므로
가벼운 호출용 경로(MODEL_LIGHT)도 내리지 않는다.

| 라우트 | 역할 | 모델 | 근거 |
|---|---|---|---|
| `/api/extract` | 발화 → 요소 추출 | `claude-opus-5` | 최대 리스크 지점. 여기서 틀리면 전 단계가 틀린다 |
| `/api/loglines` | 로그라인 3안 | `claude-opus-5` | 사용자가 "내 이야기 같다"고 느껴야 함 (가설 H3) |
| `/api/generate` | 24블록 본생성 | `claude-opus-5` | 최종 산출물. 구조 무결성 검증 대상 |
| `/api/scene-blocks` | 장면 → 블록 역산 | `claude-opus-5` | 방법론 판단이 개입 |
| `/api/benchmark` | 벤치마크 분석 | `claude-opus-5` | 76편 초안과 정합 필요 |
| `/api/suggest` | 블록별 사건 3안 | `claude-opus-5` | 창작 제안 품질 |

교체는 코드 수정 없이 환경변수로 한다: `ANTHROPIC_MODEL`(본생성), `ANTHROPIC_MODEL_LIGHT`(추출).
모델별 API 계약 차이는 `engine/model-capabilities.ts`가 흡수한다.

사용자 1명이 5단계를 완주해도 호출 비용은 수백 원대다. 초기 검증 구간에서 모델비는 병목이 아니다.

## 2. 다운그레이드 전환 기준 — 이 4개가 전부 충족되기 전에는 내리지 않는다

"나중에 저렴한 걸로 바꿔도 되는 때"를 감이 아니라 기준으로 판정한다.

| # | 기준 | 통과선 | 측정 방법 |
|---|---|---|---|
| G1 | **골든셋 존재** | 대표 발화 ≥ 20개 + 기대 추출 결과가 코드로 고정돼 있다 | `npm test` 회귀 스위트에 편입 (현 7건 → 확장) |
| G2 | **품질 등가** | 후보 모델이 골든셋에서 상위 모델 대비: 이미 말한 요소를 다시 묻는 건수 **+0**, 요소 누락률 차 **≤ 5%p**, JSON 파싱 실패·거부 폴백 발동률 차 **≤ 1%p** | 같은 골든셋을 두 모델로 돌려 비교 (섀도 호출) |
| G3 | **사용자 지표 안정** | 실사용에서 H2(질문 10개 이하 완주)·H3(로그라인 채택률) 지표가 2주 이상 기각되지 않음 | PRD v2 §5 검증 계획의 실측치 |
| G4 | **비용 동기 실재** | 월 API 비용이 예산의 30%를 넘거나, MAU 성장으로 3개월 내 넘을 전망 | 청구 대시보드 |

### 전환 순서 (한 번에 한 라우트씩)

1. `/api/suggest`, `/api/benchmark` → `claude-sonnet-5` (창작 제안·분석. 오답 비용이 상대적으로 낮음)
2. `/api/extract` → `claude-sonnet-5` (G1·G2를 **추출 골든셋으로** 통과했을 때만)
3. `/api/scene-blocks`, `/api/loglines` → `claude-sonnet-5`
4. `/api/generate`는 마지막. 최종 산출물이라 사용자 만족 지표(G3)가 가장 오래 안정된 뒤에만
5. `claude-haiku-4-5`는 추출 단독 후보로만 검토 (200K 한도·구조화 추출에 강함). 본생성에는 쓰지 않는다

### 롤백 규칙

전환 후 2주 내 G2·G3 지표가 악화되면 env 원복으로 즉시 되돌린다(배포 불필요, 재시작만).
전환·롤백 이력은 이 문서 하단에 날짜와 함께 기록한다.
