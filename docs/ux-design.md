# 모두의 창작 — UX/UI 설계서 v1

> 목표: "기능 검증용 화면"을 "작가가 만족하며 머무는 제품"으로.
> 근거: 해외 툴 12개 UX 패턴 리서치(2026-07) + 욕망의 레시피 방법론 + 김태원 감독 피드백(좌우 반전·자동 분석).

---

## 0. 제품 정의 한 줄
"좋아하는 영화의 뼈대를 빌려, 누구나 거장의 구조로 자기 이야기를 완성하는 창작 스튜디오."

디자인이 이겨야 할 감정 = **빈 화면 공포**. 디자인이 지켜야 할 명제 = **플롯은 AI, 후크는 인간**.

## 1. 사용자 정의 (Personas) — 타깃 비중 포함

### P1. "처음 쓰는 사람" — 지망생 하나 (27, 직장인, 웹소설 지망) — **주 타깃 55%**
| 항목 | 내용 |
|---|---|
| 상황 | 퇴근 후 30분~1시간. 아이디어 메모는 많은데 3화 이상 못 감. 유튜브 작법 영상만 쌓임 |
| JTBD | "내 머릿속 아이디어가 '이야기가 되는지' 오늘 밤 안에 확인하고 싶다" |
| 고통 | 빈 화면 공포 · 전문용어(플롯포인트? 미드포인트?) 울렁증 · "내 아이디어 유치한가" 불안 |
| 현재 대안 | ChatGPT에 "소설 써줘" → 밋밋한 결과에 실망 · 작법서 사놓고 안 읽음 |
| **만족 기준(측정)** | 첫 방문 10분 내 "내가 아는 영화가 24블록으로 펼쳐지는" 아하 모먼트 → 당일 내 24블록 초안 1개 완성 |
| 이탈 트리거 | 빈 폼부터 들이밀기 · 용어 설명 없는 UI · 결과가 늦거나(>20초) 로딩 침묵 |
| 기기 | 모바일로 구경(50%), PC로 작업. 밤 10~12시 |
| 한 마디 | "제가 기생충을 좋아하는데요… 그런 느낌의 이야기를 쓰고 싶어요." |

### P2. "구조가 필요한" — 준현업 서준 (38, 보조작가 출신, 공모전 준비) — 15%
| 항목 | 내용 |
|---|---|
| JTBD | "내 초고의 구조 문제(전환점 부재, 2막 늘어짐)를 객관적으로 진단받고 싶다" |
| 고통 | 툴이 유치하면 즉시 신뢰 하락 · 근거 없는 AI 조언("더 흥미롭게 하세요") 혐오 |

## 3. 디자인 원칙 6
1. **빈 화면 금지** — 모든 입력은 예시가 미리 채워져 있거나 선택지로 시작한다 (Plottr 템플릿 갤러리 패턴).
2. **용어는 이중 표기** — "전환점 (즉자→대자 욕망이 뒤집히는 순간)" 처럼 방법론 용어 + 풀이를 함께. P3에겐 정통성, P1에겐 이해.
3. **80% 자동 + 20% 선택** — AI가 초안을 깔고 사람은 고른다 (Sudowrite 리듬). 단 후크 입력만은 비워둔다 — 후크는 인간의 몫이라는 철학의 UI 구현.
4. **항상 근거 표시** — 모든 진단·제안에 출처 배지(거장 확정 / 장르 지침 / AI 제안). P2 신뢰의 핵심.
5. **안전망** — 모든 생성은 버전 스냅샷, 언제든 복구 (Save the Cat 패턴). "실험해도 잃지 않는다".
6. **선택 파급 가시화** — 블록 13을 바꾸면 영향받는 블록이 잔물결로 표시 (Dramatica 패턴, 우리만의 차별점).

## 5. 화면 스펙

### 5-1. 탐색 (다크 시네마 테마)
- **검색바(주인공)**: 큰 단일 입력. placeholder "어떤 영화처럼 쓰고 싶나요?". 자동완성 = 라이브러리(fuzzy+초성) → TMDb 후보(포스터+연도) → "제목이 기억 안 나면 줄거리로 설명해 보세요"(AI 검색).
- **포스터 그리드**: 2:3 포스터 카드, hover 시 키워드·"거장 확정" 배지. TMDb 포스터, 없으면 막색 기반 타이포 포스터 플레이스홀더.
- **분석 뷰(히어로)**: 좌 포스터+메타, 우 4막 미니바(4색 세그먼트+13 마커). 아래 4막 아코디언 → 블록 카드(소제목/줄거리/외적·내적/착안점). 상단 고정 CTA "이 뼈대로 내 이야기 만들기".
- 로딩: 단계별 문구 스켈레톤("1막을 해부하는 중…").

### 5-2. 작업실 (페이퍼 라이트 테마)
- **4막 레인 보드**: 가로 4레인(1막~4막, 막색 헤더) × 블록 카드 6장씩. 카드 상태 3종: 채움(체크) / 비어있음(점선) / AI 제안 대기(반짝 아이콘).
- **블록 카드 열기**: 기능 정의(방법론) + 벤치마크의 같은 블록(참고) + AI 제안 3카드(채택/다시/직접 쓰기). 채택하면 Keepers처럼 스토리 바이블에 축적.
- **상단 바**: 진행률 링(7/24) · 정서 곡선 미니차트 · 검증 배지(전환점✓ 적대자 9·14·18 ✓) · 버전 스냅샷.
- **나란히 모드**: 내 24블록 ↔ 벤치마크 24블록 2열 비교 (기계적 대입→창조적 변주 작업의 핵심 뷰).
- 단축키: ↑↓ 블록 이동, Enter 열기, Cmd+Z 복원 (P2).

### 5-3. 완성·내보내기
- 완성 시 축하 모먼트(포스터 스타일 표지 자동 생성 — 내 제목/로그라인).
- 내보내기: 수업 엑셀 템플릿 형식(xlsx) · docx · 공유 링크 · 인쇄(카페 제출용).

### 타이포그래피
- 본문·UI: **Pretendard Variable** (국내 사실상 표준, 무료). 코드/숫자: JetBrains Mono.
- 스케일: 12 / 13.5 / 15(기본) / 18 / 22 / 28. 행간 1.65. 블록 소제목만 세리프 옵션(RIDIBatang) — "원고" 느낌.

### 컴포넌트 인벤토리
포스터 카드(2:3) · 검색 자동완성 · 4막 미니바 · 막 레인 · 블록 카드(3상태) · AI 제안 카드 · 출처 배지 · 진행률 링 · 정서 곡선 미니차트 · 버전 스냅샷 칩 · 아하 하이라이트(전환점 앰버 링).

### 모션
150–250ms ease-out만. 블록 펼침 스태거(30ms 간격), 채택 시 카드가 바이블로 날아가는 마이크로 인터랙션 1개(과용 금지). prefers-reduced-motion 존중.

## 7. 포스터·이미지 전략 (합법)
- **TMDb API**: 무료 키, 포스터 CDN(image.tmdb.org). 조건 = 비상업 무료 + "This product uses the TMDB API…" 출처 표기. **상업 출시 시 커머셜 계약 필요**(2026-07 리서치 확인) → MVP·수업용은 무료 티어로 충분.
- **플레이스홀더**: 키 없거나 미매칭 시 막색 솔리드 + 큰 타이포(제목 첫 글자) 포스터 — 그 자체로 브랜드 룩.
- 캐시: 포스터 URL을 라이브러리 JSON에 1회 저장(매 요청 API 호출 금지).

## 8. 영화 찾기 도움 (검색 UX)
1. 라이브러리 fuzzy 매칭 — 오타·공백·초성("ㄱㅅㅊ"→기생충) 허용.
2. TMDb 자동완성 — 후보 5개(포스터·연도·감독)로 동명영화 구분.
3. **줄거리로 찾기** — "제목이 기억 안 나요" 클릭 → 한 줄 묘사 → AI가 후보 3개 제시.
4. 빈 결과 = 막다른 길 금지 — "AI로 바로 분석하기" + 인기 라이브러리 제안.

## 9. 접근성·반응형
- 명도 대비 AA(다크 테마 앰버 텍스트 주의), 키보드 완주 가능, 포커스 링 명시.
- 모바일: 탐색 풀지원(포스터 2열) / 작업실은 세로 레인 스택 + 읽기·간단 편집 위주.

## 10. 성공 지표
| 지표 | 목표 |
|---|---|
| 첫 방문 → 첫 분석 도달 | > 60% |
| 분석 → "내 이야기" 생성 전환 | > 35% |
| 24블록 완성률(7일 내) | > 20% |
| 재방문(7일) | > 30% |
| 아하 체감(분석 후 설문 1문항) | > 4.2/5 |
